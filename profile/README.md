## 🎯 À propos

Cet espace GitHub regroupe l'ensemble des **travaux pratiques et projets académiques** réalisés par Gregory MYSCILE dans le cadre du Mastère Expert en Cloud, Sécurité & Infrastructure chez Ynov Bordeaux.  
Formation en **alternance sur 2 ans**, visant l'obtention du titre **RNCP39582 Niveau 7 — Expert en Architecture des Systèmes d'Information**.

---

## 🏆 Blocs de compétences RNCP39582

| Bloc | Intitulé | Compétences clés |
|------|----------|-----------------|
| **BC01** | Élaborer la stratégie du Système d'Information | Audit SI, étude de faisabilité, SWOT, PRA/PCA, veille technologique |
| **BC02** | Gérer un projet informatique | Cadrage, planification, pilotage d'équipe, recette & livraison |
| **BC03** | Maintenir en condition opérationnelle le SI | Supervision, gestion des incidents, amélioration continue |
| **BC05** ⭐ | Concevoir l'architecture d'un SI *(spécialité Systèmes & Réseaux)* | Cartographie SI, conception réseau/cloud, IaC, automatisation, tests |

## 📚 Programme de formation

| Module | Thématiques |
|--------|------------|
| ☁️ Infrastructure Cloud | Azure (AZ-700, AZ-305), AWS, architectures hybrides |
| 🔐 DevSecOps | CI/CD sécurisé, SAST/DAST, gestion des secrets |
| 🖥️ Virtualisation | VMware vSphere, Hyper-V, VDI |
| 🌐 Réseaux avancés | VLAN, BGP, OSPF, SD-WAN, pare-feux (Stormshield, Fortinet) |
| 🐳 Conteneurisation | Docker, Kubernetes, Helm |
| 📊 Observabilité | Nagios, Prometheus, Grafana, ELK Stack |
| 🏗️ Infrastructure as Code | Terraform, Ansible, GitOps |
| 🏛️ Gouvernance SI | Pilotage, ITIL, conformité RGPD, ISO 27001 |
